# DeskBox 虚拟分组修改版

基于开源项目 [DeskBox](https://github.com/Tianyu199509/DeskBox) 修改，主要增加了「虚拟分组」模式，用法接近 360 桌面助手，但不带 360 全家桶。

原版完整介绍、下载与文档请看官方仓库：<https://github.com/Tianyu199509/DeskBox>

## 软件修改背景

我之前一直用 360 桌面助手整理桌面，很好用，但实在不喜欢 360 全家桶。后来找到开源的桌面收纳软件 DeskBox，功能不错，可是用起来总觉得差点意思，不顺手。

这个修改版就是给和我一样的用户准备的：想要 360 桌面助手那种「拖进去就收纳」的体验，又不想装 360。

## 个人优化：虚拟分组模式

在盒子右键菜单中勾选「虚拟分组模式」即可开启。

- **不移动文件**：拖入的文件只记录绝对路径，原文件留在原位置。视频剪辑工程、素材不会因为被移动而脱机。
- **桌面自动隐形**：拖入的文件如果在桌面上，会自动隐藏，桌面立刻变干净；非桌面文件只记录路径，不改变属性。支持批量多选。
- **删除与移出分开**：
  - 删除：真正把原文件送进回收站，并从盒子中移除。
  - 移出盒子 / 取消收纳：只移除记录，桌面文件恢复显示。
- **直接拖出**：把文件从盒子拖到桌面空白处，即移出盒子并恢复显示；拖拽只复制语义，绝不剪切原文件。
- **退出还原、启动收纳**：退出软件时，桌面上被隐藏的文件全部恢复显示；下次启动自动重新收纳。
- **重命名同步**：在盒子里重命名，会同步修改真实文件名并更新记录。
- **不会误清空**：取消了文件监听对盒子列表的强制同步，属性变化或桌面偶发变动不会清空盒子。

## 原版功能（简述）

本地优先的 Windows 桌面收纳工具，提供文件盒子、待办、搜索、天气、音乐等小组件。详情见 [官方仓库](https://github.com/Tianyu199509/DeskBox)。

## 构建

仓库已配置 GitHub Actions（`.github/workflows/build.yml`），推送到 `main` 后云端自动编译，产物在 Actions 页面的 `DeskBox-win-x64`。
